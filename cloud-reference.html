Training Guide

The system is designed around a simple rule: record what happened, when it happened and which machine it happened to.

👷 Assistant / Mechanic

Find the machine → report an issue or log service → add notes/photos → save. You can view history, but protected historical records cannot be rewritten.

🧭 Foreman

Review breakdowns, assign technicians, verify repairs, manage machines and make authorised historical corrections.

📊 Operations Manager

Monitor the fleet, manage people/machines/settings, review downtime and keep the Action Queue under control.

👑 Head of Operations

Full visibility and control. Use the audit trail for accountability and review the fleet picture before making operational decisions.

Fast workflow

Problem: Search machine → Report Issue → Describe → Photo → Submit.

Service: Search machine → Log Service → Work → Hours → Photo → Save.

Repair: Management verifies → resolves breakdown → downtime stops → machine returns to Working.
