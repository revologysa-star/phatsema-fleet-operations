How to use Phatsema

Use Dashboard to see current fleet status. Use Machines to update machine information and status. Use Breakdowns to report faults and follow repairs. Use Service to record maintenance and evidence. Use People, Settings and Audit for management control.

Status rules

Working = machine is operating. Available = ready for work. Breakdown = unavailable due to a fault. Maintenance = under planned maintenance. Offline = manually unavailable.
